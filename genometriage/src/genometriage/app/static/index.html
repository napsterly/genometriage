Reproduce it offline

The core judge demo and all retained evaluations run without network access or a model API.

01 · Install
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
02 · Validate
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m pip check
.\.venv\Scripts\python.exe scripts\validate_phase3_freezes.py
.\.venv\Scripts\python.exe scripts\validate_phase4.py
03 · Judge mode
.\.venv\Scripts\python.exe -m genometriage.app.run

Open http://127.0.0.1:8765
